# 发布前目录整理

2026-10-23 整理。原目录没有项目级 Git；初始化正式分支 `master`，另建 `feature/dev5.3` 保存 5.3 界面汉化，当前工作目录留在 `master`。未设置远程仓库。

主线使用 1.0.0 的最终 dev15 字体源码、5.2r1 区域源码和冻结输入法源码。各组件及生成资源放入独立目录；源码来源与 SHA-256 见 `product-inputs.json`，全部迁移和历史验收路径映射见 `source-migration.json`。

`release/` 只保留 1.0.0 正式目录、原 ZIP 和 ZIP 校验文件。它们全部保持原始字节，包括原验收报告和历史来源路径。`docs/release/1.0.0` 提供便于阅读的说明副本；`docs/verification/1.0.0` 保留最终引用的截图、原始状态、失败／补跑记录及最终报告，不保留测试闪存。历史路径属于当时证据，不代表现在仍存在同名目录。

清理范围：旧版及重复发布介质、各代候选 PKG、过时一次性探针、故障注入模拟器、旧 CMake 构建树和对象文件、多份测试闪存、过程截图／画廊、过时计划与实施文档、打印中间文件、缓存及系统杂项。必要的字体基线、邮政快照、工具源码、运行依赖和干净测试基线集中到 `external`。

5.3 分支另存最新 ChineseUI、DisplayCompat、相关测试源和冻结记录；它未完成整体汉化验收，不属于 1.0.0 正式安装组合。分支包含独立构建和冻结内容检查入口。使用 `git switch feature/dev5.3` 查看，完成后可用 `git switch master` 返回正式主线。
