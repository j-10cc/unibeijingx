# UniBeijingX 1.0.0

作者：j10cc · j10cc.site · Powered by GPT6.1-Sol

本版采用 dev15 已冻结的字体包，中文显示修复和 About 均内置于字体包。应用界面保持英文；安装字体后，受支持的中文内容自动显示，无需手动切换字体。

## 四个安装包

| 文件 | 内容 | 安装选择 |
| --- | --- | --- |
| Font-Lite.pkg | 8,309 个映射字符；9／12／16 点原生位图、自动显示适配及 About | 与 Full 二选一 |
| Font-Full.pkg | 同一字符集；9／10／12／14／16／18 点原生位图、自动显示适配及 About | 与 Lite 二选一 |
| ChineseRegion.pkg | 中文月份、星期、日期解析、人民币、公制、A4、中国邮政地址辅助 | 需要中文区域时安装 |
| Pinyin.pkg | 拼音候选栏与原生字母键盘配合输入中文 | 需要中文输入时安装 |

发行包包含四个 PKG；通常实际安装三个（一个字体包＋区域包＋输入法），也可以只安装所需组件。两种字体使用相同包标识，不能同时安装。安装新版 Lite 或 Full 后，字体列表只显示一个 UniBeijingX 中文字体选项；区域包使用的内部兼容名称不再单独出现在列表。

区域和输入法沿用已冻结的正式二进制，未重新编译。发行版本为 1.0.0；字体 About 显示 1.0.0，Newton 原生包头的整数版本沿用 1，不能据此认为支持直接覆盖升级。

## 安装或换版

1. 备份数据。升级或从 Lite 换到 Full 时，先关闭 Find、编辑表单和输入浮窗，移除旧 Pinyin IME、Chinese Region、UniBeijingX，做一次普通软重启。不要直接覆盖同标识旧字体包。
2. 安装 Font-Lite.pkg 或 Font-Full.pkg。中文显示适配自动启用，默认纯英文内容继续使用系统字体。
3. 按需安装 ChineseRegion.pkg，再安装 Pinyin.pkg。
4. 需要中文区域时，在 **Extras → Prefs → Locale → Country** 选择 **中国**。首次安装区域包仅注册条目；曾启用过的设备可能恢复原选择。选择区域不等于切换字体。
5. 在 Extras 打开 **UniBeijingX**，检查 About 的 Lite／Full、Version 1.0.0、Developed by j10cc、j10cc.site 和 Powered by GPT6.1-Sol。

中文区域保留 City、State、Zip Code 等英文标签。时区仍用 Newton 原生城市设置；地址邮编库不会设置系统时区。

## 拼音输入

先将光标放入目标文本字段，打开 Pinyin IME，点候选栏右侧 **ABC** 使用原生字母键盘。输入小写全拼后点候选字，或用空格选择当前页第一项；数字键也可选词。单字页最多 10 项，词语页最多 7 项。候选栏支持翻页、中／英切换和关闭；Extras 可重新打开。

换到另一输入字段后，先确认光标，再点 ABC 绑定。极快切换字段并立即输入仍受原生焦点交接影响。

## 日期和地址

Names 生日／纪念日文本字段支持 ISO 日期和完整中文日期，例如 `2026-10-22`、`2026年十月22日`。Dates 的日历行继续使用原生选择器。无效日期不应覆盖原值。

中国地址可通过 **State → City → Zip Code** 查询省市、区县及邮编，长列表使用 Previous page／Next page；仍可手动输入。邮编按字符串保存，保留前导零。数据为中国邮政 2026-10-15 快照，覆盖大陆 31 个省级地区；应核对实际投递地址。

Chinese Address 打印格式按中文地址顺序组织内容。实物打印和硬件通信未经验收，本版不作相关通过声明。

## 卸载

关闭编辑表单和输入浮窗后，按输入法、区域、字体顺序移除。区域包恢复所管理的原区域及设置；后续用户自行更改的设置应保留。卸载字体不会删除中文记录，但英文 ROM 本身无法绘制这些汉字。

## 验收范围和已知边界

本次在独立 Einstein 模拟器中，以原始 MP2000 ROM 和 Newton OS 2.1 **(712000)-1** 状态验收。详细结果见随包 ACCEPTANCE_zh-CN.md。真实 MessagePad 硬件尚待复验。

本版不宣称覆盖全部 Unicode。加载期间首帧方框在稳定后可读、可读的“周”字底行裁切按既定标准接受；-10061 是已知未解决的问题，本次排除其专项及压力触发验证，不表示该错误已经修复；本次验收不包含 -10061 专项或压力触发、8 小时长程、旧笔记兼容性和真实硬件通信。长文件夹标题等极端边界以实际可读为通过标准，不要求严格控件间距或完美布局。地址性能按不超过 256 字符验收，1,440 字符长地址性能不列为问题。

SHA256SUMS 提供安装包与文档校验值，MANIFEST.json 记录来源。LICENSES 与 DATA_SOURCES.md 包含字体及词典许可和数据说明。本包不含 ROM、模拟器、闪存、QA 探针或界面汉化包；历史 5.2r1 发行介质保持原样。

本次验收覆盖范围、逐项状态及未能到达的入口均在 ACCEPTANCE_zh-CN.md 中列出。本轮修复与验收构成 1.0.0 的最终结论；后续新发现的问题归入下一版本。
